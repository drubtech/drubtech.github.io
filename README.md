# Web de Drub Tech

Se publica con GitHub Pages en **https://drubtech.github.io** desde el repositorio público
`drubtech/drubtech.github.io`. Esta carpeta es el original: se edita aquí y se publica con:

```bash
git subtree push --prefix web pages main
```

(una vez: `git remote add pages https://github.com/drubtech/drubtech.github.io.git`)

| Página | Dirección |
|---|---|
| `index.html` | https://drubtech.github.io |
| `vatio/index.html` | https://drubtech.github.io/vatio/ |
| `vatio/privacidad.html` | https://drubtech.github.io/vatio/privacidad — **la que va en Play Console** |
